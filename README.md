# 🌐 meusite.html

Um projeto de site pessoal desenvolvido com **HTML puro**, focado em aprendizado e prática das principais tags e estruturas da linguagem de marcação da web.

---

## 📋 Sobre o Projeto

Este repositório contém o código-fonte de um site criado para praticar e demonstrar o uso de **HTML** na construção de páginas web. O projeto faz parte da jornada de aprendizado em desenvolvimento web, cobrindo desde a estrutura básica de uma página até o uso de elementos semânticos.

---

## 🛠️ Tecnologias Utilizadas

- ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) **HTML5** — estrutura e marcação do conteúdo

1. Clone o repositório:
2.    ```bash
         git clone https://github.com/MIcodebot/meusite.html.git
         ```
      2. Abra o arquivo `index.html` no seu navegador.
  
      3. ---
  
      4. ## 📚 Conceitos Praticados
  
      5. - Estrutura básica do HTML (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
         - - Tags de texto (`<h1>` a `<h6>`, `<p>`, `<strong>`, `<em>`)
           - - Listas ordenadas e não ordenadas (`<ul>`, `<ol>`, `<li>`)
             - - Links e imagens (`<a>`, `<img>`)
               - - Formulários básicos (`<form>`, `<input>`, `<button>`)
                 - - Semântica HTML5 (`<header>`, `<main>`, `<footer>`, `<section>`)
